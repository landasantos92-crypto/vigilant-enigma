# 🔢 API REST - Conversor Numérico

API REST desenvolvida em Node.js e Express para realização de conversões de sistemas numéricos (ex: Decimal para Binário). O projeto conta com testes unitários e de integração automatizados (Jest/Supertest), além de documentação interativa via OpenAPI/Swagger.

---

## 🛠️ Tecnologias Utilizadas

* **Node.js**: Ambiente de execução JavaScript.
* **Express**: Framework para roteamento e gerenciamento da API HTTP.
* **Jest**: Framework para execução dos testes unitários.
* **Supertest**: Biblioteca para testes de integração de rotas HTTP.
* **Swagger UI / OpenAPI**: Documentação interativa das rotas.
